# Sicherheit

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version auf der
[Release-Seite](https://github.com/Nikiphedia/Pirol/releases/latest).

## Sicherheitslücke melden

Bitte **kein öffentliches Issue** eröffnen. Melde Sicherheitslücken vertraulich über GitHub:
[Security → Report a vulnerability](https://github.com/Nikiphedia/Pirol/security/advisories/new).

Hilfreich sind:

- betroffene Version und Gerät
- eine Beschreibung der Lücke und wie man sie nachvollziehen kann
- mögliche Auswirkungen (z.B. Zugriff auf Aufnahmen, Standortdaten oder gespeicherte Zugangsdaten für den Upload)

Du erhältst in der Regel innerhalb von 14 Tagen eine erste Antwort. Bitte gib uns Zeit für eine Korrektur, bevor du
Details veröffentlichst.

## Was PIROL speichert

PIROL arbeitet offline. Aufnahmen, Erkennungen und Standortdaten bleiben auf dem Gerät, bis du sie selbst
exportierst oder hochlädst. Zugangsdaten für den NAS-Upload werden verschlüsselt im Android Keystore abgelegt.
